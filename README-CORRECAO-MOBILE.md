# Correção dos botões no celular

Substitua no GitHub todos os arquivos deste pacote.

A correção usa um mapa SVG de 1152 × 2048. A imagem e as zonas de toque agora
crescem e diminuem juntas, evitando o deslocamento observado no celular.

Depois do commit:
1. Aguarde alguns minutos.
2. Feche completamente o navegador ou app instalado.
3. Abra o site novamente.
